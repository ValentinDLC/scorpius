Méthode de travail

OBO est actuellement configuré pour la recherche et le suivi d'entreprises à prospecter.

  1. Rechercher des entreprises dans Prospects.
  2. Consulter les coordonnées et les résultats d'audit.
  3. Sélectionner les entreprises intéressantes.
  4. Les retrouver dans Missions à venir.
  5. Suivre les appels, relances et résultats commerciaux.

Installation mobile

Vous pouvez installer OBO comme une application sur votre téléphone.

  • Android : menu Chrome → Ajouter à l'écran d'accueil.
  • iPhone : Partager dans Safari → Sur l'écran d'accueil.
  • Ordinateur : utiliser le bouton Installer du navigateur si disponible.
